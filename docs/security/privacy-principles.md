# Princípios de Privacidade

- Coletar o mínimo necessário.
- Explicar finalidade de dados pessoais.
- Separar dados operacionais, auditoria e conteúdo privado.
- Não enviar dados sensíveis à IA sem necessidade e autorização.
- Redigir ou resumir prompts e respostas quando possível.
- Definir retenção antes de produção.
- Permitir exclusão e anonimização quando compatível com obrigações de segurança e auditoria.
- Considerar LGPD e operação internacional, sem tratar este documento como aconselhamento jurídico.
