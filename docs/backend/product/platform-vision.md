# Platform Vision

Trevvos is a platform and product umbrella, not a single app.

KM One is the current main product. It serves drivers with context, personalization and operational intelligence, while keeping the Android app offline-first. Trevvos API becomes the central backend that can support KM One and future Trevvos apps without each product inventing its own backend.

The public portal is an acquisition, content and contact surface. It will present the company, publish SEO-oriented articles, capture leads, expose the app catalog and provide an interactive contact experience assisted by an LLM.

The backend is the central brain of the platform. It should own shared data, audit trails, consent history, future identity, future billing, shared AI access and product-specific contexts.

Azure is the default future cloud target. The platform should be easy to run locally first, then deploy to Azure App Service, Azure Database for PostgreSQL Flexible Server, Key Vault, Application Insights, Storage and Azure AI Foundry/Azure OpenAI when each stage becomes necessary.

AI is a real product differentiator, but it has clear limits. It can summarize, guide, personalize and explain evidence. It must not replace deterministic calculations, promise demand, guarantee rides or hide uncertainty.
